Central Processing Unit (CPU)

Brain of the Computer

The CPU performs all calculations and executes instructions from software. It controls every operation performed by the computer.

Functions

  • Executes program instructions
  • Performs arithmetic calculations
  • Controls computer operations
  • Communicates with RAM and storage

Random Access Memory (RAM)

Temporary Memory

RAM temporarily stores data used by currently running programs. More RAM allows better multitasking.

  • Temporary storage
  • Fast data access
  • Supports multitasking
  • Data is lost after shutdown

HDD / SSD Storage

Permanent Storage

Storage devices save files permanently. HDD uses spinning disks, while SSD uses flash memory and is much faster.

  • Stores Windows/Linux
  • Stores documents
  • Stores photos and videos
  • Keeps data after power off

Peripheral Ports

Ports connect external devices to the computer.

  • USB – Keyboard, Mouse, Flash Drive
  • HDMI – Monitor or Projector
  • Ethernet – Internet Connection
  • Audio – Speakers & Headphones

System Software

System software manages computer hardware and provides a platform for application software.

  • Windows
  • Linux
  • macOS
  • Android
  • Device Drivers
  • BIOS / UEFI

Application Software

Application software helps users perform specific tasks.

  • Microsoft Word
  • Microsoft Excel
  • Google Chrome
  • Adobe Photoshop
  • Zoom
  • VLC Media Player

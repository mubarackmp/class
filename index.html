Central Processing Unit (CPU)

Brain of the Computer

The CPU performs all calculations and executes instructions from software. It controls every operation performed by the computer.

Functions

  • Executes program instructions
  • Performs arithmetic calculations
  • Controls computer operations
  • Communicates with RAM and storage

Motherboard

Main Circuit Board

The motherboard is the main printed circuit board that connects all the computer components together. It allows communication between the CPU, RAM, storage devices, graphics card, and peripherals.

  • Connects all hardware components
  • Contains CPU socket
  • Provides RAM slots
  • Supports expansion cards

Random Access Memory (RAM)

Temporary Memory

RAM temporarily stores data used by currently running programs. More RAM allows better multitasking.

  • Temporary storage
  • Fast data access
  • Supports multitasking
  • Data is lost after shutdown

Graphics Processing Unit (GPU)

Graphics Processor

A Graphics Processing Unit (GPU) renders images, videos, and animations. It is essential for gaming, video editing, and 3D applications.

  • Processes graphics
  • Improves gaming performance
  • Supports video editing
  • Used in Artificial Intelligence

Power Supply Unit (PSU)

Power Source

The Power Supply Unit converts AC electricity into DC electricity required by computer components.

  • Supplies power to motherboard
  • Powers CPU and GPU
  • Provides electricity to storage devices
  • Protects hardware from power fluctuations

CPU Cooling System

Cooling

The CPU cooling system removes heat from the processor and keeps the computer running safely.

  • Prevents overheating
  • Improves system stability
  • Extends CPU lifespan
  • Available as Air or Liquid Cooling

Computer Cabinet (Case)

Protective Enclosure

The computer cabinet houses and protects all internal hardware components. It also helps with airflow and cooling.

  • Protects internal hardware
  • Supports cooling fans
  • Organizes cables
  • Available in ATX, Micro-ATX and Mini-ITX sizes

HDD / SSD Storage

Permanent Storage

Storage devices save files permanently. HDD uses spinning disks, while SSD uses flash memory and is much faster.

  • Stores Windows/Linux
  • Stores documents
  • Stores photos and videos
  • Keeps data after power off

Optical Drive

CD/DVD Reader

An optical drive reads and writes data using CDs, DVDs or Blu-ray discs.

  • Reads CDs and DVDs
  • Burns data onto discs
  • Useful for software installation
  • External USB drives are available

Cache Memory

Ultra Fast Memory

Cache memory is located inside the CPU and stores frequently used data to improve processing speed.

  • Very high speed
  • Reduces CPU waiting time
  • L1, L2 and L3 cache
  • Improves overall performance

CMOS Battery

BIOS Memory

The CMOS battery supplies power to save BIOS settings and maintain the system clock when the computer is turned off.

  • Stores BIOS settings
  • Maintains date and time
  • Usually CR2032 battery
  • Easy to replace

Input Devices

User Input

Input devices allow users to send data and commands to the computer.

  • Keyboard
  • Mouse
  • Scanner
  • Microphone
  • Webcam

Output Devices

Computer Output

Output devices display or produce the results processed by the computer.

  • Monitor
  • Printer
  • Projector
  • Speakers
  • Headphones

Peripheral Ports

Ports connect external devices to the computer.

  • USB – Keyboard, Mouse, Flash Drive
  • HDMI – Monitor or Projector
  • Ethernet – Internet Connection
  • Audio – Speakers & Headphones

SATA & M.2 Connectors

Storage Connectors

These connectors allow HDDs and SSDs to communicate with the motherboard.

  • SATA connects HDD and SSD
  • M.2 supports NVMe SSD
  • High-speed data transfer
  • Used in modern computers

PCI Express Expansion Slots

Expansion

PCI Express slots allow additional hardware such as graphics cards, sound cards and Wi-Fi cards to be installed.

  • Supports GPU installation
  • Adds Wi-Fi cards
  • Supports capture cards
  • High-speed communication

Network Interface Card (NIC)

Network Hardware

A Network Interface Card allows the computer to communicate over a wired or wireless network.

  • Provides internet connectivity
  • Supports LAN communication
  • Available as Ethernet or Wi-Fi
  • Transfers data between computers

Sound Card

Audio Hardware

A sound card processes audio signals and provides high-quality sound output and recording.

  • Plays music
  • Records audio
  • Supports speakers and microphones
  • Can be built into the motherboard

System Software

System software manages computer hardware and provides a platform for application software.

  • Windows
  • Linux
  • macOS
  • Android
  • Device Drivers
  • BIOS / UEFI

Application Software

Application software helps users perform specific tasks.

  • Microsoft Word
  • Microsoft Excel
  • Google Chrome
  • Adobe Photoshop
  • Zoom
  • VLC Media Player
